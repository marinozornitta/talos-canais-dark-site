Privacy Policy

talos-canais-dark is a personal tool used only by its owner.

What it does with Google/YouTube data

With the owner's authorization, it uses YouTube API Services solely to (1) upload videos, thumbnails and captions to the owner's own YouTube channel and (2) read that channel's video analytics (views, watch time and audience retention).

What it collects

It does not collect, store on any server, share, transfer or sell data about any other person. The OAuth credentials (including the refresh token) are stored only on the owner's own computer, and can be revoked at any time at myaccount.google.com/permissions.

YouTube API Services

This application uses YouTube API Services and is subject to the YouTube Terms of Service and the Google Privacy Policy.
